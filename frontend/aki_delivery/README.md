# AKI Delivery

Projeto estático de pedidos e entregas.

## Perfis disponíveis no login

O campo **Tipo de acesso** do `index.html` apresenta:

1. Administrador
2. Colaborador
3. Entregador
4. Cliente

Cada opção direciona para sua respectiva tela:

- `pages/administrador.html`
- `pages/colaborador.html`
- `pages/entregador.html`
- `pages/cliente.html`

# AKI Delivery

Projeto estático de pedidos e entregas com perfis de Administrador, Colaborador, Cliente e Entregador.

## Recursos
- Tela inicial de login em `index.html`, com a identidade visual Aki Delivery.
- Perfil de Administrador com pedidos, catálogo, estoque, pagamentos, mensagens e configurações.
- Perfil de Colaborador com acesso operacional limitado.
- Perfil de Cliente com cardápio, carrinho, acompanhamento e checkout.
- Perfil de Entregador com entregas, histórico, ganhos e forma de pagamento.
- Cardápio com fotos reais hospedadas por URLs de imagens, detalhes em modal, descrição, quantidade e adição ao carrinho.
- Produtos: hambúrgueres, porções, hot dogs, combos, bebidas, sucos, açaí, sorvete e pudim.
- Formas de pagamento: Pix, cartões, dinheiro e vale-refeição.
